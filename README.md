## Run locally
Open `index.html` using VS Code Live Server.

## Add your song
Place your chosen audio file at `assets/music/our-song.mp3`. The player is click-to-play and does not autoplay. Use an audio file you have permission to use.

## Map and privacy
Leaflet + OpenStreetMap require an internet connection. Current pins use approximate public-place coordinates for Hauz Khas, Deer Park and Sanjay Van. No exact home address is included. Do not publish a precise residential marker.

## Deployment
Deploy the whole project folder to Netlify. Keep `index.html` at the project root. The requested Netlify subdomain is subject to availability.
